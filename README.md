# ASTEROIDS · CRT EDITION

复古街机《小行星》重制版：HTML5 Canvas 渲染游戏画面，再经 WebGL CRT 着色器做后期处理，并加入原创「引力井」道具玩法。

## 运行

无需构建、无需服务器 —— 直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge / Firefox）。

## 操作

| 按键 | 功能 |
| --- | --- |
| ← / →（或 A / D） | 旋转飞船 |
| ↑（或 W） | 推进 |
| 空格 | 射击 |
| E / Shift | 部署引力井 |
| P | 暂停 |
| M | 静音 |
| Enter | 开始 / 确认 |

## 特性

- **CRT 着色器**（WebGL 片元着色器）：屏幕曲率（桶形畸变）、闪烁扫描线、荧光辉光（bloom）、RGB 荫罩、色散、滚动亮带、噪点与暗角；WebGL 不可用时自动降级为 CSS 扫描线。
- **引力井道具**：拾取「G」胶囊获得充能（上限 3），按 E 在飞船位置部署。引力井在 4.5 秒内将半径内的小行星螺旋聚拢（也会轻微牵引飞船，可用推进器挣脱），随后引爆，击碎爆炸半径内所有小行星并计分。坠入奇点的小行星会被直接粉碎。配有漩涡粒子、收缩光环、引爆预警圈、冲击波与屏幕震动。
- **六级小行星**：6 种尺寸，击碎后分裂为 2 个下一级碎块，最小级直接销毁；越小分值越高（20 → 200）。
- **经典机制**：惯性物理、屏幕边缘环绕穿越、3 条生命、每 10000 分奖 1 命、波次递进、重生无敌闪烁。
- **最高分排行榜**：localStorage 持久化，前 10 名，街机风格 3 字母签名录入。
- **合成音效**：WebAudio 实时合成的射击 / 爆炸 / 推进 / 拾取 / 引爆音效，无需音频文件。

## 文件

- `index.html` — 全部游戏代码（单文件，无外部依赖）
- `test/smoke.js` — 无头冒烟测试（`node test/smoke.js`），模拟 DOM 跑通完整游戏流程
